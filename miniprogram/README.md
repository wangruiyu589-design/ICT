# 澜枢 LANSHU · 配套微信小程序

原生微信小程序，配套同目录上级的澜枢灌溉平台。总览、分区灌溉、定时计划、告警和设备连接共 5 个标签页。页面使用蓝色为主的设计，并针对移动端重新安排信息层级。

## 开发者工具中运行

1. 按主项目说明启动本地 API 服务，默认地址为 `http://127.0.0.1:8787`。
2. 在微信开发者工具中选择「导入项目」，项目目录选择此 `miniprogram` 文件夹。
3. 项目使用 `touristappid` 作为游客调试标记，未冒用或伪造小程序 AppID。若当前开发者工具不接受游客模式，改为你自己名下的小程序 AppID。
4. 在「详情 → 本地设置」启用「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`project.config.json` 已设置开发用 `urlCheck: false`。
5. 点击编译。首次读取 `GET /api/state` 后显示真实的本地服务状态。页面不包含独立的演示数据，也不会在服务离线时伪造成功结果。
6. 若更换服务端口，在「我的 → 服务连接」填写地址并点击「保存并连接」。此配置只保存于当前小程序本地存储。

本项目没有额外 npm 依赖，不需要在开发者工具中构建 npm。编译所需的 JS、JSON、WXML、WXSS 和 PNG 标签栏图标均包含在目录中。

## 手机调试

- 手机和电脑连接同一个局域网。小程序中的 `127.0.0.1` 指向手机自身，不能访问电脑。
- 后端需以 `HOST=0.0.0.0` 监听，并允许 Windows 防火墙的局域网入站访问 TCP 8787。只在可信局域网内联调。
- 在「我的 → 服务连接」设置为电脑的局域网 IP，例如 `http://192.168.1.20:8787`。
- 真机调试需要开发者自己名下的小程序 AppID 和相应开发权限；游客标记不能代替正式资质。
- 本地 HTTP 连接需通过微信开发者工具的真机调试/调试选项放行域名校验。普通预览或正式版本不能依赖上述开发设置。
- 正式上线前需要受信任的 HTTPS 域名、微信合法请求域名配置和用户认证。本项目当前定位为本地模拟系统，尚未对接实际电磁阀或传感器。

## 功能和交互

| 页面 | 已实现功能 |
| --- | --- |
| 总览 | 农场概况、当日用水、土壤含水率、设备在线数、告警数、天气、最近 7 天用水、操作日志 |
| 灌溉 | 全部/灌溉中/待补水/离线筛选，按分钟启动，单区停止，全部停止，离线禁用，操作二次确认 |
| 计划 | 新建计划、选择分区和执行日、北京时间、时长校验、保存后启用开关、启停、删除 |
| 告警 | 待处理/已知悉/全部筛选，查看详情、等级与来源，确认已知悉 |
| 我的 | 服务地址保存与连接、复制地址、农场信息、设备状态和本地联调说明 |

每个页面进入时读取后端，每 15 秒刷新一次，支持下拉刷新。离开页面后停止该页面的轮询。请求超时为 12 秒。连接中断会显示明确错误及上次同步数据，并禁用操作按钮；恢复后自动更新。启动灌溉和计划时间受服务端规则约束，后端始终是最终状态来源。

修改类 API 成功后，页面直接使用服务端返回的完整状态更新；失败时保留错误信息，不会通过本地改标签来假装设备已执行。告警「确认知悉」仅记录确认状态，不表示硬件问题被修复。

## API 契约

所有接口均返回完整状态对象，包含 `zones`、`devices`、`plans`、`alerts`、`logs`、`history`、`sessions`、`settings`、`farm`、`weather`、`updatedAt`、`mode`。

| 方法 | 地址 | 请求体 |
| --- | --- | --- |
| GET | `/api/state` | 无 |
| POST | `/api/zones/:id/start` | `{ "duration": 20 }` |
| POST | `/api/zones/:id/stop` | `{}` |
| POST | `/api/stop-all` | `{}` |
| POST | `/api/plans` | `{ "name": "清晨补水", "zoneIds": ["分区ID"], "startTime": "06:00", "duration": 20, "days": [1,2,3,4,5,6,7], "enabled": true }` |
| POST | `/api/plans/:id/enabled` | `{ "enabled": false }` |
| DELETE | `/api/plans/:id` | 无 |
| POST | `/api/alerts/:id/ack` | `{}` |

`days` 中 1 表示星期一，7 表示星期日。任务执行依赖电脑上的 API 进程持续运行。暂停/删除计划不隐含停止已经开始的灌溉，请在灌溉页单独停止。

小程序启停计划使用服务端提供的 POST 兼容入口。微信官方 `wx.request` 的方法类型没有列出 PATCH，因此不直接使用网页端的 PATCH 接口。[微信官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)

## 验证和限制

在当前目录运行 `node scripts/check.cjs`，检查所有 JavaScript 语法和 JSON、页面资源、标签栏图片与模板引用。图标可用 `node scripts/generate-icons.cjs` 重新生成。

运行 `node scripts/integration-check.cjs` 会使用微信 API mock 加载实际页面代码，并连接独立启动的真实本地 API。测试数据创建于 `scripts/work/`，结束后清理，不修改日常演示数据。测试覆盖总览同步、离线禁控、时长校验和上限默认值、单区启停、全部停止、计划新建/暂停/删除、告警确认、断网与错误数据、旧请求竞态和连接地址配置。

本交付已通过静态代码检查和上述页面逻辑/隔离 API 联调，不声称已经通过微信开发者工具编译、微信真机验收或实体设备联调。实际微信渲染、域名策略和设备控制链路仍需要使用你的微信环境和设备进行验收。建议在开发者工具中完成：修改服务地址 → 读取农场 → 启动分区 → 网页端确认同步 → 停止分区 → 新建并暂停/删除计划 → 确认告警 → 断开 API 检查错误提示。
