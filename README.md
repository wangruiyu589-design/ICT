# 澜枢 LANSHU · 智慧灌溉

蓝色系灌溉管理平台与原生微信小程序，共用本地模拟 API。本项目仅在本地运行，未创建云资源、未部署公网。

## 现在就运行

已在 Windows 11、Node.js 22.17.1 环境构建。推荐 Node.js 22.12 或以上版本。

在 Git Bash 中：

```bash
cd /e/claude_make/lanshu-irrigation
npm install --cache ./work/npm-cache
npm run dev
```

也可以双击项目目录中的 `start-local.cmd`。如果依赖已安装，启动器不会重新安装。

- 网页平台：<http://127.0.0.1:5173/>
- 移动网页版：<http://127.0.0.1:5173/?mobile=1>
- 本地 API：<http://127.0.0.1:8787/api/health>

使用期间保持启动终端运行；按 `Ctrl+C` 结束。端口已被占用时请关闭本项目旧的启动终端再启动，不会自动改用未知端口。

## 已实现

| 模块 | 可操作功能 |
| --- | --- |
| 运行总览 | 实时统计、可点击缩放的分区示意图、当前分区控制、模拟天气、待处理事项、近7/14天趋势 |
| 分区灌溉 | 6个示范分区、筛选搜索、墒情与流量、设置时长、开始/停止、超时自动停、停止全部 |
| 设备管理 | 在线离线筛选、设备搜索、详情、电量、信号与最近通信时间 |
| 灌溉计划 | 新建、编辑、暂停、启用、删除、选择分区和重复日期，按北京时间自动执行 |
| 灌溉决策 | ET₀、Kc、降雨、有效降雨比例、灌溉效率输入；计算单日需水，展示各步公式 |
| 用水分析 | 7/14/30天模拟历史、趋势、每日记录、CSV导出 |
| 告警中心 | 离线示范事件、动态低墒情告警、确认、历史、操作日志；持续异常去重 |
| 平台设置 | 农场名称、地区、墒情预警阈值、单次灌溉上限，保存到本地 |
| 微信小程序 | 总览、灌溉、计划、告警、我的五个原生页面；连接同一个 API，共享操作结果 |

网页支持小屏布局与键盘操作，弹窗支持 Escape 关闭。读取失败时显示上次同步信息并暂停控制，不会伪报操作成功。

## 微信小程序

将 `miniprogram` 文件夹导入微信开发者工具，选择小程序项目。

- 项目使用 `touristappid` 作为本地调试占位，不包含 AppSecret。
- 先启动上述本地 API。
- 在开发者工具的本地设置中开启“不校验合法域名、web-view、TLS版本以及HTTPS证书”，用于本地 HTTP 模拟调试。
- 小程序“我的”中可修改接口地址；模拟器默认 `http://127.0.0.1:8787`。
- 预览和真实发布通常需要自己的微信小程序 AppID；此项目没有替你注册、审核或发布。

手机真机的 `127.0.0.1` 指手机本身。需要同一局域网调试时，先停止旧服务，在 Git Bash 运行：

```bash
HOST=0.0.0.0 npm run dev
```

然后把小程序接口地址改成 `http://电脑局域网IP:8787`。此选项仅改变 API 的监听地址，网页开发服务器仍限本机。防火墙如有提示，只为可信本地网络允许 Node 访问。模拟 API 没有用户鉴权，勿开放到公网。

更多小程序操作、调试方法与验证范围见 `miniprogram/README.md`。

## 数据与计算边界

数据保存在 `server/data/state.json`。第一次启动生成示范农场，之后重启继续使用原数据。请勿让两个 API 进程共用同一个数据目录。

- 设备、天气、初始历史、初始告警均为模拟内容；没有连接真实阀门、气象站、地图服务或外部数据库。
- 分区图是交互示意图，没有精确地理坐标；目前分区与设备使用固定示范配置，没有现场硬件配网或分区增删管理。
- 灌溉流量单位为 L/min；用水量按实际经过时间累计为 m³；墒情、电量与信号为 %，管道压力为 MPa。
- 计划需要本地服务运行，关机期间不补跑历史计划。离线和已灌溉分区跳过并记录原因。暂停/删除计划不会结束已启动任务；请使用停止按钮。
- 启动灌溉会保存结束时刻，重启会关闭已经到时的模拟任务并累计对应模拟水量。
- 低墒情事件恢复后保留历史记录，确认只表示已经知悉。
- 需水计算是透明规则演示，通用 Kc 示例没有按当地作物标定；没有训练或接入强化学习模型。墒情 % 不会被误当成稻田水层 mm。
- 需水估算不包括前期土壤缺水、根区蓄水、渗漏与渠道水力模型；点击结果仅打开控制面板，用户需要另外核对灌溉时长。

## 参考来源与实现区别

参考网站为 <https://smart.zrwater.cn/>，公开演示为 <https://smart.zrwater.cn/simple-irrigation.html>。公开内容包含田块配置、需水预测、灌溉决策和渠系配水。首页为模块入口门户，部分内部页面的公开路由声明需要认证；本项目未绕过认证，也没有验证它的真实后端。

本项目重新设计了运营控制台和移动端，从零实现布局与本地接口，没有复制参考站源码、品牌或静态资源。参考站的完整模型预报、ETo地图和渠系水力优化不在当前本地首版内。后续接入真实灌溉系统时，应补充设备协议适配、身份权限、实际气象来源、数据存储与经过校准的农艺模型。
